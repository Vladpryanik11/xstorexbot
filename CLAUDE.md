# xstorexbot

Telegram-бот продажи подписок на закрытый канал: тарифы, оплата через Platega, выдача ссылки на вступление, сертификаты Apple. Отдельный проект со своим репозиторием и сервером. Главный документ: `docs/superpowers/specs/2026-11-06-xstorexbot-design.md`. Если задача ему противоречит, сначала обновите спецификацию вместе с владельцем.

## Общение

- С владельцем общаемся на русском.
- Все тексты бота на русском. Даты для покупателя — `ДД.ММ.ГГГГ` по Москве.

## Процесс (обязателен)

1. Спецификация в `docs/superpowers/specs/`.
2. План в `docs/superpowers/plans/`.
3. Код по TDD: сначала падающий тест.
4. Перед словами «готово» запустите проверки и покажите вывод.

## Жёсткие правила

- Только собственные IPA владельца.
- Секреты (токен бота, ключи Platega, ключ шифрования, пароль резервных копий) не попадают в git, логи и тексты ошибок.
- Сертификаты хранятся только зашифрованными.
- Суммы в копейках, время в UTC.
- Интеграционные тесты идут только на настоящей PostgreSQL 17. PostgreSQL для разработки слушает `127.0.0.1:5433`, потому что порт 5432 на машине занят базой сайта.

## Команды

| Команда | Что делает |
|---|---|
| `pnpm dev` | запуск с перезагрузкой, читает `.env` |
| `pnpm build` / `pnpm start` | сборка и запуск `dist/main.js` |
| `pnpm lint` / `pnpm format` | Biome |
| `pnpm typecheck` | `tsc --noEmit` |
| `pnpm test` | модульные тесты |
| `pnpm test:int` | интеграционные тесты (нужен `pnpm db:up`) |
| `pnpm db:up` / `pnpm db:down` | PostgreSQL для разработки (порт 5433) |
| `pnpm db:migrate` | миграции Prisma |

Перед «готово»: `pnpm lint && pnpm typecheck && pnpm test && pnpm test:int`.
