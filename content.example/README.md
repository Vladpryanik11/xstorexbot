# Папка content

Скопируйте `content.example` в `content` и поправьте тексты. Тексты — HTML в подмножестве Telegram (`<b>`, `<i>`, `<code>`, `<a href>`).

- `start.txt` — приветствие, подпись к картинке, не длиннее 900 символов.
- `about.txt` — «О сервисе», не длиннее 4000 символов.
- `feather.txt` — шаги установки в Feather, не длиннее 4000 символов.
- `start.jpg` — картинка приветствия: JPEG (начинается с `FF D8 FF`), не больше 10 МБ. В репозитории её нет, положите свою.
