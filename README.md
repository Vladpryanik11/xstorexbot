# xstorexbot

Telegram-бот подписок. Дизайн: `docs/superpowers/specs/2026-11-06-xstorexbot-design.md`.

## Первая настройка

1. `cp .env.example .env` и заполните значения.
2. `pnpm install`
3. `pnpm db:up` (PostgreSQL на `127.0.0.1:5433`)
4. `pnpm db:migrate`
5. Скопируйте `content.example/` в `content/` и поправьте тексты.
6. `pnpm dev`

## Проверки

```
pnpm lint
pnpm typecheck
pnpm test
pnpm test:int
```

`pnpm test:int` берёт `DATABASE_URL_TEST` из окружения, а если его нет, то из `.env` (читается только эта переменная).

## Запуск

- Разработка: `pnpm dev` (читает `.env`, перезапускается при правках).
- Продакшен-режим: `pnpm build && pnpm start` (`dist/main.js`; переменные окружения задаёт среда).
- Остановка: `Ctrl+C` / `SIGTERM` — бот дожидается текущих обновлений и закрывает соединение с базой.
- Без `.env` процесс завершится с кодом 1 и перечислит неверные переменные (значения не выводятся).

## Проверка на тестовом боте

Нужны токен отдельного тестового бота, тестовый чат заказов и `content/` с `start.jpg`. Заполните `.env` сами, токен никому не пересылайте. Ключи Platega и `CERT_ENCRYPTION_KEY` на этапе 1 могут быть тестовыми значениями нужного формата.

1. `pnpm db:up && pnpm db:migrate`, затем `pnpm dev`.
2. `/start` показывает картинку, текст и 5 кнопок.
3. «Каталог приложений», «Отзывы», «Поддержка» открывают ссылки; «О сервисе» присылает текст.
4. «Купить подписку» → «90 дней — 1170 ₽» → «Подписка: 90 дней / Стоимость: 1170 ₽ (390 ₽ в месяц)», ссылка на оферту, «Назад» возвращает к списку.
5. `/terms` и `/paysupport` отвечают.
6. `/start` в чате заказов не вызывает ответа.
7. В логе нет токена.
